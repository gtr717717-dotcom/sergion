---
description: Обновить данные сайта (PubMed + ClinicalTrials.gov + конференции) одним запросом
---

Ты обновляешь данные трекера конференций. Источник истины — `js/import-data.js`,
который генерируется скриптом `scripts/build-import-data.mjs`. Личные поля
пользователя (оценка, заметки, статус посещения, «в календаре») живут в localStorage
и при пересборке НЕ теряются — `js/import.js` делает upsert по importId. Делай строго:

1. Синхронизация: `git pull --rebase` (если есть локальные правки — сначала закоммить их).

2. (Опционально) Если в `$ARGUMENTS` передана новая тема — обнови константу `TOPIC`
   в начале `scripts/build-import-data.mjs`: поле `pubmed` (запрос E-utilities) и
   `ctgov` (term для ClinicalTrials.gov). Если `$ARGUMENTS` пустой — тему не трогай.

3. Пересборка данных: `node scripts/build-import-data.mjs`
   (Node 20+, нативный fetch, без npm-зависимостей). Скрипт перезапишет `js/import-data.js`
   и выведет в консоль количество конференций/исследований/статей.
   Примечание: RU-описания добавляются только если задан env `ANTHROPIC_API_KEY` — без него
   скрипт работает, поле descRu остаётся пустым. Не требуй ключ.

4. Покажи, что изменилось: `git --no-pager diff --stat js/import-data.js`
   и итоговые счётчики из вывода скрипта.

5. Коммит и пуш:
   `git add js/import-data.js scripts/build-import-data.mjs`
   `git commit -m "chore: refresh import-data.js"`
   `git push`
   (если diff пустой — просто скажи «данные не изменились» и не коммить).

6. Напомни: чтобы увидеть свежие данные локально — перезагрузить `index.html`
   (Ctrl+R). На GitHub/Pages данные обновятся после пуша.

Работай молча по шагам, в конце дай короткий отчёт: сколько стало конференций/исследований/статей
и что запушено.
